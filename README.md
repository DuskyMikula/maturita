# Maturitná práca – Učebná pomôcka (Postman a MikroTik REST API)

**Téma č. 16:** Vytvorte učebnú pomôcku – POSTMAN, Restapi Mikrotik  
**Konzultant:** Ing. Mojmír Vrana  

## Cieľ práce
Vytvoriť učebnú pomôcku zameranú na prácu s REST API rozhraním systému MikroTik RouterOS (bežiacom vo virtuálnom stroji MikroTik CHR) pomocou nástroja Postman a vlastného programu v jazyku Python.

## Štruktúra repozitára
- `dokumentacia/` – písomná časť maturitnej práce (Word dokument)
- `01-mikrotik-chr/` – postup inštalácie virtuálneho stroja MikroTik CHR a aktivácia REST API
- `02-postman/` – zdokumentované REST API požiadavky a export kolekcie z nástroja Postman
- `03-cvicenia-ip/` – praktické cvičenia na zistenie a úpravu IP adries
- `04-program-sluzby/` – program na automatickú konfiguráciu DHCP, Syslog a SNMP servera
